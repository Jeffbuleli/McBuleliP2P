# Formation ops NGEMBA — Bloc Citoyen Amani (BCA) · 30 min

> **Public :** opérateurs BCA (Bukavu / Uvira) · **Référent :** Josué Assani  
> **Support :** info@ngemba-rdc.org · hi@mcbuleli.org  
> **Profil :** [31-BCA-BLOC-CITOYEN-AMANI.md](./31-BCA-BLOC-CITOYEN-AMANI.md)

---

## Objectifs

1. Comprendre NGEMBA (orienter, pas remplacer urgences / police).
2. Se connecter au dashboard ONG **filtré Sud-Kivu**.
3. Prendre en charge enfant en danger, école, orientation paix / communauté.
4. Discrétion, escalade, clôture.

---

## 1. Contexte (5 min)

- **NGEMBA** = canal citoyen → triage IA → opérateur humain BCA (zone Sud-Kivu).
- **URL :** https://ngemba-rdc.org/ops/login
- **Code opérateur :** transmis par McBuleli (email / WhatsApp sécurisé) — ne pas partager.
- Aligné sur votre mandat : paix (*Amani*), protection de l’enfance, cohésion communautaire.

---

## 2. Connexion & file (5 min)

1. Ouvrir `/ops/login`.
2. Saisir le **code BCA**.
3. File = alertes **Sud-Kivu** (Bukavu, Uvira…) dans vos catégories — pas tout le pays.
4. Badges : 🔴 Critical · 🟠 High · 🟢 Info.

**Exercice :** ouvrir une alerte test « enfant / école » à Bukavu.

---

## 3. Cas types Sud-Kivu (8 min)

| Cas | Action BCA |
|-----|------------|
| Enfant de rue / danger immédiat | Prise en charge → notes → orientation médiation / centre partenaire |
| Safe School (harcèlement, violence) | Écoute → référent école si dispo → partenaire VBG si besoin |
| Signalement communauté (tensions, harcèlement) | Triage → orientation confession / réseau BCA · pas d’arbitrage police |
| Urgence vitale | **112 / SAMU / police d’abord** · documenter ensuite sur NGEMBA |

---

## 4. Script d’ouverture (7 min)

> « Bonjour, je suis [prénom], opérateur·rice NGEMBA pour le Bloc Citoyen Amani.  
> Êtes-vous en sécurité pour parler maintenant ? »

Checklist : lire résumé IA + message · confirmer lieu · **Prendre en charge** · Notes · Orienter / Clôturer.

Escalade : danger de mort → urgences RDC ; débordement → info@ngemba-rdc.org + hi@mcbuleli.org.

---

## 5. Règles (5 min)

- Pas de partage du code ops ni de captures d’écran PII sur WhatsApp/Facebook.
- Pas de promesse judiciaire ou policière.
- Respect de la [charte ONG](https://ngemba-rdc.org/legal/charte-ong).
