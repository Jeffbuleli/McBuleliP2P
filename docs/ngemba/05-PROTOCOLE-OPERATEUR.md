# Protocole opérateur ONG - brouillon Phase 0

> À valider avec l’ONG pilote avant le MVP.

## 1. Principes

1. **Croire d’abord** - une alerte urgente n’est jamais ignorée pour « historique douteux ».
2. **Ne pas re-victimiser** - pas de jugement, pas d’interrogatoire agressif.
3. **Sécurité d’abord** - si danger immédiat → numéros d’urgence + orientation, pas de long chat.
4. **Discrétion** - ne jamais rappeler / SMS sans accord si risque agresseur.

## 2. File d’attente

| Badge | Action |
|-------|--------|
| 🔴 Critical | Prendre **immédiatement** (cible &lt; 5 min heures pilote) |
| 🟠 High | Sous 15-30 min |
| 🟢 Info | Ressources / clôture avec message |

## 3. Script d’ouverture (exemple)

> « Bonjour, je suis [prénom], opérateur·rice NGEMBA pour [ONG].  
> Vous êtes en sécurité pour parler maintenant ? Oui / Non. »

Si **Non** → mode discret : messages courts, pas de détails à voix haute.

## 4. Checklist dossier

- [ ] Lire résumé IA (ne pas le coller tel quel au citoyen)
- [ ] Confirmer localisation **si partagée**
- [ ] Identifier besoin (abri, médical, écoute, juridique…)
- [ ] Orienter / assigner
- [ ] Noter actions dans le dossier (journalisé)
- [ ] Clôturer ou planifier suivi

## 5. Escalade

| Situation | Action |
|-----------|--------|
| Vie en danger immédiat | Numéros locaux + procédure ONG |
| Enfant en danger | Protocole protection de l’enfant |
| Opérateur débordé | Escalade admin ONG · ne pas laisser en file sans ack |

## 6. Fausses alertes

- 1ère : rappel bienveillant des règles
- Répétées manifestes : restriction progressive **sauf** nouvelle urgence critique

## 7. SLA affiché au citoyen (MVP)

> « En heures d’ouverture de notre partenaire, une personne vous répond sous quelques minutes.  
> En dehors, votre alerte est enregistrée et les numéros d’urgence restent disponibles. »
